# Glossary
- **Golden master**: captured production outputs of the legacy batch (repo `legacy/data/golden/`) that the new system must reproduce.
- **Business day / BUSDATE**: the date the nightly batch runs for; the batch runs every calendar day.
- **TXN-REF**: the channel's own reference on a transaction (mobile, web, ATM).
- **Parity**: byte-for-byte agreement with the golden master, except approved deviations.
