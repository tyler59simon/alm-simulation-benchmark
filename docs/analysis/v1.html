Reading

Scenario v1 has two runs: Living Memory on (the first full run) and a memory-off control. They are history more than a controlled comparison:

  • Different quizzes. The LM run took only the memory-only quiz (the repo quiz did not exist yet); the control took only the repo quiz. No quiz row compares the two.
  • The control is not a clean A0. It disabled Living Memory's hooks but left Claude Code auto-memory on (the harness learned to switch both off in v2).
  • Different scenario files and harness. Between the runs, Phase 0 added facts P1 to P3 to the ground truth, changed the quiz and the team briefing, and added the planted mistakes. The comparability table below shows the changed hashes.

What is still comparable: work cost and efficiency per session, re-reads, repeated failures, CI and merges. The main result of v1 is the LM run's own: memory held little team knowledge, mostly because facts were never captured. That result drove the Living Memory remediation phases and the realistic scenario v2.
